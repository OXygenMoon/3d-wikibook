# 格子社区 · 本地班级社区

基于 Three.js 的低多边形多人社区。模型、账号、班级数据与浏览器资源都在本地运行；P0 起使用 PostgreSQL（本地默认嵌入式 PGlite）持久化，会话与消息不再因重启丢失。

当前开发状态见 [开发进度](docs/开发进度.md)，架构与验证边界见 [数据结构与运行边界](docs/数据结构与运行边界.md)。[工程地基](docs/工程地基.md) 保留 P0 历史记录。

## 启动与登录

```sh
npm install
npm start
```

打开 [http://127.0.0.1:4173/](http://127.0.0.1:4173/)，也可以双击 `启动 Cubicles.command`。
默认管理员账号 **lzy**，密码 **123456**。点击顶部“登录”后进入；管理员登录后显示“管理后台”。默认创建“创想一班”，包含 6 列 × 4 行、中心间距 7 米的 24 个工位，管理员拥有第一个工位。

本地默认使用嵌入式 PGlite，数据位于 `.local-data/pglite/`，无需安装 Docker。首次启动如果数据库为空且存在 `.local-data/community.json`，会自动导入并保留原文件。

### 使用 PostgreSQL / Docker

```sh
cp .env.example .env
# 修改 POSTGRES_PASSWORD 与 DEFAULT_ADMIN_PASSWORD
docker compose up --build
```

`compose.yaml` 会启动 Postgres 和应用，把 `./.local-data` 挂载为 `/data`，首次启动自动导入旧数据。也可以只启动 Postgres，然后本地执行：

```sh
DATABASE_URL=postgres://cubicles:cubicles@127.0.0.1:5432/cubicles npm start
```

Node.js 20.19+。依赖已安装；复制到另一台电脑后先执行 `npm install`。

源码推送和本轮独立 systemd／PGlite 服务端部署见 [GitHub 与服务端部署](docs/GitHub与服务端部署.md)。公网开放前须先设置强管理员密码；本地默认开发密码不能作为公网部署密码。

## 管理员后台

- **世界与模型**：一格一米的建筑布局编辑器，默认在 3D 场景中点选拖动，支持树木／路灯独立布置、占地检查、旋转、GLB 模型库、总图规划、撤销／重做与统一保存。模型导入支持名称、描述、按比例缩放和实时 3D 预览，再放入世界。详见 [世界建模与导入](docs/世界建模与导入.md) 和 [3D 模型与工位编辑器](docs/3D模型与工位编辑器.md)。
- **区域与间距**：创建班级区域，设置中心 X/Z、行列、工位间距和区域颜色。左侧规划图显示班级区和四个公共区。点击已有班级修改；区域移动和间距变化会保留账号与家具。会检查区域重叠、公共区冲突、社区边界及已有工位容量。
- **名单导入**：读取 CSV 文件或粘贴 CSV。支持 `账号,密码,姓名,班级` 或 `username,password,name,class` 表头，支持带引号的逗号与换行。班级必须事先创建。导入后创建独立账号并自动分配空工位。账号重复、格式错误或工位不足时整批不写入。
- **账号与分配**：把用户转移到空工位，个人布置跟随迁移。账号不能占用他人已有工位。
- **昼夜设置**：自动模式按北京时间，06:00–18:00 白天，其余为夜间；手动模式可指定 0–23 小时。所有访客使用同一设置。

CSV 示例（示例账号不会自动创建）：

```csv
账号,密码,姓名,班级
student01,123456,小林,创想一班
student02,123456,小雨,创想一班
```

世界范围为 280×280 格，每格 1 米。建筑有独立占地；班级区内包含 5×5 格个人工位。当前单个区域最多 8×8 工位，间距可调整数 6–10 米，社区总计最多 256 个工位。需要更大容量时，应先增加区域流式加载并压测。

## 工位与背包

账号拥有独立背包和一个工位。抵达自己的工位入口后，下方“背包”会变为“布置”；按 **B** 打开家具编辑。其他位置按 B 查看背包，可以使用“返回我的工位”。只有工位主人能够编辑，服务器同时校验账号、位置、物品数量和摆放范围。

编辑器直接在 3D 场景中点选、拖动家具或模型，按 R 旋转、Delete 收回背包，也保留侧栏精确调整；不再需要虚拟平面画板。拖动越界会恢复原位。移动／旋转书桌会带动桌面物品。保存后，账号再次登录仍保留布置；取消恢复上次保存版本。包括原木书桌、学习椅、电脑、笔记本、绿植、花束、落地灯、仙人掌、盆景和水杯。

工位同时是一个迷你世界编辑器：登录用户可以从背包导入自己的 3D 模型（名称、描述、缩放、3D 预览），再放入自己的工位。个人模型仅自己可见；管理员共享模型可设为全员可用或任务解锁。支持模型元信息编辑、缩略图、使用统计，工位编辑支持 0.25 米吸附、撤销／重做和复制。详见 [3D 模型与工位编辑器](docs/3D模型与工位编辑器.md)。

## 班级课堂

管理员可指定教师及负责班级。教师在“班级课堂”发布公告、导入本班名单、分配工位、发布任务和审核提交；学生提交文字或 HTTP(S) 作品链接。教师确认完成后，服务端幂等发放活力、家具和共享模型资格，个人记录与班级榜单同步更新。作品仅在学生主动勾选后展示。详见 [班级课堂](docs/班级课堂.md)。

## WikiBook 迁移开发

目标是分阶段独立承接 WikiBook 全部功能，不只是接入旧站。管理员后台的“WikiBook 迁移”仅预检，不写账号或奖励；第二批已提供独立来源身份表、原密码兼容和受停服／备份／计划指纹约束的离线学生导入，没有网页写入接口，未执行真实学生导入。步骤与未完成边界见 [身份迁移验收](docs/WikiBook身份迁移验收.md)，完整范围见 [迁移规划](docs/WikiBook迁移规划.md)。源码审计及其保护单测需要 Python 3.9+；实际导入源码需源项目 Python 依赖，普通服务和离线学生导入不依赖 Python。

在线账号工位显示绿点，离线显示灰点，离线布置不消失。夜间在线工位出现暖光灯泡、地面光晕和屏幕发光，最近的三个在线工位启用真实点光；离线工位不亮灯。断开连接约 12 秒后判定离线，明确退出立即移除在线状态。

## 公共区域

右侧地点按钮与地图只负责导航到区域入口，不会直接弹出功能。实际进入区域后出现 **E** 提示；按 E 或点击提示才打开对应内容。服务器也校验公共区位置。

- **荷风池塘**：实体池岸、水面、荷叶荷花、芦苇、木钓台和动态涟漪。到达后可钓鱼，服务器根据抛竿与收线时间判定结果，成功 +10 活力。
- **共创贴纸墙**：实体立墙、木框、纸张和长椅。登录用户发布文字贴纸；最新 27 张绘制到实际三维墙上，最多保留 60 张。
- **排行榜殿堂**：可步入的柱廊、奖杯、领奖台和展柜。榜单读取账号真实活力，按成绩排序。
- **云端机房**：12 台电脑、桌椅、讲台和任务卡。包含社区入门与空间设计练习，每项首次完成 +5 活力；空间设计任务需要先保存家具布置。

## 数据和运行方式

- 数据库是唯一事实源：生产使用 PostgreSQL，本地默认使用 `.local-data/pglite/`。账号、班级、模型、建筑、工位和课堂记录已拆为独立表；`community_state` 只保留社区元数据。密码使用 scrypt 哈希，不保存明文密码。
- `sessions` 表保存登录会话、在线位置和临时状态；`messages` 表保存最近聊天；服务器重启后原 Cookie 仍可继续使用。
- `.local-data/community.json` 是首次启动的导入种子与兼容备份，不再作为运行时唯一存储。
- `.local-data/models/` 保存上传的自包含 GLB；模型名称、描述、尺寸、缩放、所有者与可见性保存在 `modelAssets`。第一次升级会自动备份原社区数据到 `before-grid-migration.json`。
- 登录使用 HttpOnly、SameSite=Strict Cookie 与独立访客会话；管理员接口、个人编辑和公共互动均由服务端校验。
- 默认只监听 `127.0.0.1`；Docker Compose 中监听 `0.0.0.0`。所有写入均为本地或自建数据库。
- 当前只支持一个应用写进程，启动锁拒绝第二个写者；业务拆表不等于可水平扩容。位置心跳默认每 2 秒批量持久化，登录／退出和业务保存即时写入。
- 旧原型的 `world.json` 留在原处作为历史数据；本版本使用 PostgreSQL/PGlite 与 `community.json` 导入种子。

```sh
npm run check        # 语法检查 + ESLint
npm test             # 单元与集成测试
npm run build        # 生成 dist 静态资源
npm run preview      # 使用 dist + 相同本地 API 预览
E2E_PRODUCTION=1 npm run test:e2e  # 构建后验证生产静态资源及浏览器流程
npm run test:performance          # 隔离环境 30 人接口压测
npm run test:deployment           # 独立 Docker / PostgreSQL 部署、重启和恢复验收
DATABASE_URL=postgres://.../cubicles_test npm run test:postgres  # 创建并删除临时测试库
npm run db:backup -- manual
npm run db:restore-drill
```

数据库迁移、备份、回滚与 Docker 验收细节见 [完整备份与部署验收](docs/完整备份与部署验收.md)。真实设备与第二台机器尚未验证，不能把本机压测结果当成生产容量承诺。

云端机房按 E 可打开 WikiBook OJ，支持沉浸全屏、返回世界并保留当前 OJ 页面。入口由 `WIKIBOOK_OJ_URL` 配置，账号仍使用 WikiBook 登录；详见 [OJ 机房接入](docs/OJ机房接入.md)。

荷风池塘按 E 打开 WikiBook 的完整钓鱼模块，支持返回世界、沉浸和独立标签页；地址由 `WIKIBOOK_FISHING_URL` 独立配置。鱼饵、渔获、星星和排行由 WikiBook 管理，暂不与社区活力联动；详见 [WikiBook 钓鱼池塘接入](docs/WikiBook钓鱼池塘接入.md)。

这是可本地使用的社区版本。OJ 暂为页面入口集成，真实课程成绩／判题／奖励尚未迁入；语音通话和图片贴纸上传未接入，社区任务卡仍是本地任务。
