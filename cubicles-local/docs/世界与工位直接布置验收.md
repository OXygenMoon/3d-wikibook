# 世界与工位直接布置验收

## 世界编辑器

- 入口：管理后台 → 世界与模型 → 进入世界建造编辑器，默认直接进入三维布置。
- 世界从 140×140 米扩至 280×280 米，X/Z 边界、场景地面、地图、网格、班级位置校验和服务端位置上报统一使用 `GRID`。
- 外围 50 棵树、22 盏路灯变为独立的持久化景观记录；可新增、点选拖动、旋转、收起或回收，也可替换为自己导入的共享 GLB。
- 点选实际树灯／GLB 网格，公共建筑通过实例拾取识别归属；班级／工位也可点选占地或从列表选择。
- R 旋转 90°，Delete 回收可移除的物件；空白处拖动转视角，右键拖动平移，滚轮缩放。保留网格总图和坐标精调。
- 移动班级会带动全部工位；工位归属和家具不变。班级／工位不能误删或任意旋转。
- 世界冲突／越界草稿显示红色选框和原因，禁止保存；可继续调整或撤销。请求进行时锁定编辑，失败保留草稿，布局版本冲突仍由服务端返回 409。
- 景观／GLB 拖动直接更新物体位置，避免每次指针移动重建世界；班级和内置公共建筑的预览重建节流至约 100 毫秒一次，松手后统一刷新。
- 非编辑状态下景观仍批量实例化；回收实例不删除 GLB 资源。

## 个人空间

- 登录并抵达自己的工位入口后按 B，直接点选 3D 家具／模型拖动；不再出现虚拟平面画板。
- 选中对象的旋转、复制、收回背包按钮优先显示；空间名称与配色折叠到设置中，避免遮住三维操作。
- R 每次旋转 15°，Delete 收回背包，保留坐标／旋转精调、0.25 米吸附、撤销／重做。
- 移动／旋转书桌会带动桌面物品；收回书桌同时收回桌面物品，可撤销恢复。
- 无效拖动松手后恢复拖动前的位置，触控取消同样恢复，保留原来的撤销／重做分支。
- 射线拾取只包含本人工位家具；服务器继续检查主人、到场、背包数量、模型权限、桌面承托和边界。
- 取消恢复已保存布置，保存后刷新仍保留；保存期间不允许场景拖动。
- 窄屏使用底部约 44% 高度的编辑面板，并调整相机取景；通过触屏拖动事件验证，不代表已完成真机验收。

## 边界

地面、道路和小车仍不是可编辑物件；公共建筑内部装饰仍跟随整栋建筑。当前仍为单写入服务，最多 256 工位、400 条世界布局记录（含景观／工位），没有借扩图取消容量保护。原生景观暂不开放自由缩放，可通过共享 GLB 外观和占地尺寸替换。未进行新的真机、第二台机器或生产容量验收。
