# 世界建模与导入

## 管理员操作

1. 登录管理员账号，打开 **管理后台 → 世界与模型 → 进入世界建造编辑器**。
2. 默认进入三维布置，点选树木、路灯、导入模型或公共建筑后直接拖动；也可在侧栏输入网格 X、Z，设置朝向。班级／工位可点选地面占地或从列表选择。
3. 在“我的模型库”点击“导入模型”，选择本地 `.glb` 文件，填写名称、描述和缩放倍率；右侧会实时预览 3D 效果和导入后尺寸。
4. 点击资源旁的“放入世界”，系统按模型实际宽深自动寻找空闲网格。设置建筑名称、占地宽深、位置和方向。
5. R 旋转 90°、Delete 回收可移除物件，右键拖动平移视角、空白处拖动转视角、滚轮缩放；“返回网格总图”保留原有二维精确规划功能，最后点击“保存世界布局”。关闭编辑器会放弃未保存的布局。

地图可以放大、缩小、全图、定位选中建筑，支持最近 30 步撤销与重做。模型库资源可以重复放入世界；移除一个建筑实例不会删除原始模型文件。

## 模型尺寸与缩放

导入时 `1.0` 表示模型最长边 1 米，缩放保持比例、不拉伸。例如原始最长边 4 米的凉亭：

- 缩放 1.0 → 最长边 1 米
- 缩放 4.0 → 最长边 4 米
- 缩放 0.5 → 最长边 0.5 米

导入后最长边等于缩放倍率（米）。世界编辑器会根据实际宽深向上取整生成占地；保存时占地不能小于模型实际宽深。用户在自己的工位里也使用同一套尺寸规则。

模型原始包围盒由服务端根据 GLB 顶点计算，并考虑节点平移、旋转与缩放。

## 网格规则

- 每格 1 米，世界范围 X、Z 均为 -140 到 140，共 280×280 格（上边界不含，完整占地不得超出）。
- X 向东增加，Z 向南增加。坐标表示**旋转后占地矩形的左上角**，需要为整数。
- 建筑自身宽、深为旋转前尺寸；90° 或 270° 时实际占地宽深互换。只支持 0°、90°、180°、270°。
- 独立建筑不得相互重叠，不能越过世界边界；允许相邻建筑共用一条边。
- 班级区域是一个父区域，里面可以排列若干个人工位。工位占 5×5 格，必须完全位于所属班级区内，工位之间不能重叠。
- 移动班级区会带动其全部工位，账号归属与家具布置不变。勾选“显示个人工位”后可单独移动工位。
- 班级的行列数与间距在“区域与间距”调整；调整后会重新排列本班工位，保留账号和家具。
- 收起公共区或自定义建筑后，它不显示，也不占地；公共区同时暂停对应入口和功能。重新显示仍需满足占地检查。

外围 50 棵树和 22 盏路灯现在是独立景观记录，可新增、移动、旋转、收起、回收，也可在“模型外观”中替换为自己制作的共享 GLB。内置树木占 3×3 格、路灯占 1×1 格；恢复内置外观时同时恢复默认占地。回收实例不删除模型资源。

旧布局首次启动迁移一次：保留班级、工位、原建筑和家具；原景观网格化，和已有占地冲突的景观先收起而不移动已有建筑。回收后的景观不会在重启时重新生成。公共建筑内部的装饰仍随整栋建筑移动，地面、道路与小车仍不是可编辑景观对象。

地图扩展不等于无限容量：仍为单社区最多 256 工位、世界布局最多 400 条记录，含景观和工位。三维拖动发生冲突时保留草稿并标红，必须解决后才能保存。

## 在建模软件中制作

建议先下载编辑器中的 [4×4 米凉亭示例](../public/examples/grid-pavilion.glb)，在 Blender 等软件中导入参考。

1. 以 1 单位 = 1 米制作，Y 轴向上，模型底部放在地面，入口建议面向 +Z。
2. 应用物体缩放与旋转，并尽量把外观、贴图整理在同一工程中。
3. 导出 **glTF 2.0 Binary（.glb）**，贴图嵌入文件。Blender 导出器会转换坐标轴。
4. 使用 PNG/JPEG 贴图和常规材质。当前不启用 Draco、Meshopt、KTX2 压缩，也不加载模型引用的外部网址或文件。
5. 每个文件不超过 20 MiB、30 万个网格三角形、50 万个 POSITION 顶点、2000 个节点。重复节点渲染仍有成本，请控制模型复杂度和贴图大小。

导入后模型按选择的缩放倍率渲染，底部自动贴地、水平居中；不会拉伸模型。世界占地负责网格占用；默认精细碰撞直接使用模型表面，较窄模型会在占地内留出可通行空间。建议将建筑的所有装饰、屋檐都包含在导出范围内。

平台保留原始 GLB。动画、骨骼角色、模型内的灯光和交互脚本不属于当前建筑编辑功能；动画不会自动播放。请在自己的电脑保留 `.blend` 等工程源文件。

## 替换已有公共建筑

选中池塘、贴纸墙、殿堂或机房，在“模型外观”中选择已导入资源。可以调整占地，但原有功能仍绑定在该建筑上；导航与互动入口会跟随位置和朝向。

“物理碰撞”默认使用精细模型碰撞，保留门洞和柱间空隙，并可在模型表面落脚；也可明确选择“整块实心占地”或“不参与碰撞”。旧凉亭无需重传，刷新页面后即使用精细模式。贴纸墙替换自定义模型后仍可打开贴纸面板，但不会自动把贴纸贴到未知模型表面。

重新选择“使用内置模型”会恢复公共建筑的默认占地和外观。

新增的自定义建筑提供外观、占地和精细／实心／无碰撞三种模式。创建新的业务功能、传送门或钓鱼区域仍需接入相应功能逻辑。

## 数据与备份

- PostgreSQL / PGlite：建筑、景观、占地、模型目录、班级、工位和用户数据；`community.json` 仅作为旧格式导入来源，不是当前在线数据库。
- `.local-data/models/`：导入的 GLB 文件；重建 `dist` 不影响它们。
- `.local-data/before-grid-migration.json`：第一次升级为网格世界时自动备份的原始社区数据。

备份时请同时复制整个 `.local-data` 文件夹。多个管理员窗口同时编辑时，以先保存的版本为准；过期草稿会被服务器拒绝，需关闭编辑器后重新打开。

精细碰撞、二段跳落脚和范围限制见 [精细碰撞与跳跃验收](精细碰撞与跳跃验收.md)。
