# 本轮开发验收

范围：完整备份与部署、模型／工位编辑器、教师班级课堂、学习奖励、受控试用前的性能和数据地基。

## 已通过

- 静态语法、ESLint 和生产静态资源构建。
- 55 项单元／集成测试：GLB 校验、访问隔离、编辑规则、角色权限、任务奖励、迁移恢复、会话和事务故障。
- 真实 PostgreSQL 上另跑备份 4 项、领域事务 4 项、课堂 6 项，共 14 项；创建并清理临时测试库。
- 16 条生产构建浏览器测试：登录、三维进入、编辑保存、贴纸、模型、账号切换隐私、教师审核发奖闭环、断网恢复、窄屏和重模型场景。
- Docker 镜像从源码构建并运行 PostgreSQL：首次旧数据导入、私有模型下载、完整跨驱动恢复、Cookie 与聊天重启保留。
- 30 账号接口负载与 56 工位／30 独立重模型的限速渲染测量；具体数值与设备限制见 [数据结构与运行边界](数据结构与运行边界.md)。

## 复跑

在 `cubicles-local` 下执行：

```sh
npm run check
npm test
npm run build
E2E_PRODUCTION=1 npm run test:e2e
DATABASE_URL=postgres://<用户>:<密码>@<主机>:<端口>/cubicles_test npm run test:postgres
npm run test:deployment
npm run test:performance
PERF_MODEL=stress npm run test:performance
```

PostgreSQL 专项只允许数据库名含 `test` 或 `validation`，连接账号需有创建临时库权限。性能专项默认创建隔离 PGlite；切换 PostgreSQL 使用 `PERF_DATABASE_URL`，必须是可丢弃测试库。不要指向真实社区。Docker 验收创建独立 Compose 项目，结束清理自己的容器、数据卷与临时目录；不会删除预先存在的镜像。

本机证据在 `.tmp/acceptance/`，该目录不提交版本库；Playwright 报告在 `playwright-report/`，截图在 `test-results/`，后两者会被下一次浏览器测试覆盖。

## 真实数据升级

升级前已生成包含数据库与模型的完整备份，并在隔离环境完成恢复演练。升级后逐项比较世界数据，保留原 1 个账号、28 个工位、2 个区域和 1 个模型，没有向实际社区写入合成测试用户。

当前页面为 [本地社区](http://127.0.0.1:4173/)，服务继续运行。正式部署前需要更换默认凭据、HTTPS、安全 Cookie 与备份保存策略。

第二台机器、真实低配设备／手机、真实班级课时，以及外部课程平台联调均未执行，需要用户提供对应环境或组织参与。外部平台目前只有契约，没有实际适配器。不得将本机测试解读为这些外部项目已验收。
